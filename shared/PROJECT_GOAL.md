# Mission

Read and follow the documents in this workspace (architecture, implementation, and roadmap.md's). Add to the roadmap.md more details like verification to those that need it.
Before each work segment: check the task board, read recent mail, and review your MEMORY.md.
Complete sprints/tasks one at a time, in order - finish, test, commit, update the board, then move to the next.
Work together: assign tasks on the board, peer-review work, keep states current.
If the workspace has no docs yet, write them first (plan the project into sprints), then follow them. Create an AGENTS.md as a worklog/history and update it after every sprint.
